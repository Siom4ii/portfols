SecondLife

A mobile app designed to give old items a second chance — buy, sell, or trade pre-loved stuff in a clean, user-friendly interface.

About the App

SecondLife is a mobile app I created that promotes sustainability through reusability. Users can list, browse, and trade second-hand items easily. It’s built with Java for the Android front-end and PHP + MySQL for the backend. I also integrated Firebase for image hosting and authentication.

This project reflects my passion for both design and functionality — blending modern UI design with a seamless experience.

Features

What makes SecondLife unique:

01

User-friendly interface for buying, selling, or trading items.

02

Image upload using ImgBB and Firebase for real-time updates.

03

Secure user login and registration with PHP and MySQL backend.
