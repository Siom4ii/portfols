# Kevin Clark Portfolio

This is a static portfolio site. It has no dependencies or build command.

## Deploy to Vercel

1. Push this folder to a Git repository and import it in [Vercel](https://vercel.com/new), or run `vercel` from this folder with the Vercel CLI.
2. Leave the framework preset as **Other** and leave the build command and output directory empty.
3. Deploy.

`vercel.json` rewrites the root URL (`/`) to `html/index.html`. All existing CSS, JavaScript, media, and project pages remain served from their current paths.
